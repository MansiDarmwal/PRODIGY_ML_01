# PRODIGY_ML_01

## House Price Prediction using Linear Regression

This project is part of my Machine Learning internship at Prodigy Infotech.

For this task, I implemented a Linear Regression model to predict house prices using features such as living area, number of bedrooms, and number of bathrooms.

### Dataset

The dataset used for this project is the House Prices - Advanced Regression Techniques dataset from Kaggle.

### What I did

- Loaded and explored the dataset
- Selected the required features
- Handled missing values where needed
- Split the data into training and testing sets
- Trained a Linear Regression model
- Made predictions on the test data
- Evaluated the model's performance

### Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

### Files

- `PRODIGY_ML_01.ipynb` - Jupyter Notebook containing the complete implementation
- `README.md` - Project information

### Conclusion

This task helped me understand how Linear Regression can be used to predict continuous values and how different house features can affect the predicted price.
